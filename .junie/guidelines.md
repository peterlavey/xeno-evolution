# Task Management Guidelines

These guidelines explain how to work with the `docs/tasks.md` checklist.

## Task Updates
- Mark tasks as `[x]` when completed.
- Do not remove completed tasks.
- If a task needs adjustment, update its description but keep the `Plan Link` and `Requirement Link` intact.

## Adding New Tasks
- If a new technical requirement is discovered, add it to the appropriate phase in `docs/tasks.md`.
- Every new task MUST include:
    - A clear description.
    - A `Plan Link` pointing to the relevant item in `docs/plan.md`.
    - A `Requirement Link` pointing to the relevant item in `docs/requirements.md`.

## Maintaining Consistency
- Follow the existing Markdown formatting.
- Ensure tasks remain grouped by logical phases.
- Keep the `docs/tasks.md` file synchronized with the actual progress of the implementation.
